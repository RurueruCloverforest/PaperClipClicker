# Material

加工前の画像など、ゲーム制作に使用する元素材の保管場所です。

- 1素材につき1フォルダを作成してください。
- 各素材フォルダに元素材と `MATERIAL.md` を入れてください。
- 素材が未生成の場合は、`MATERIAL.md` に説明を書き、`PLEASE_GENERATE_ME.md` を未生成の目印として置いてください。
- 素材を生成して記録を更新したら、`PLEASE_GENERATE_ME.md` を削除してください。
- ゲームからこのフォルダ内の素材を直接参照しないでください。
- 詳細な管理方法はプロジェクト直下の `ARTWORK.md` を確認してください。
