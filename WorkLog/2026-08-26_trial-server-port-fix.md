# 試用サーバーのポート競合修正

## 実施内容

- 固定ポート4173の競合によって試用サーバーが起動できない問題を修正した。
- ポート4173～4192から利用可能な番号を自動選択するようにした。
- WindowsのURL予約に依存する `HttpListener` を廃止し、管理者権限が不要なローカルTCPサーバーへ置き換えた。
- テスト時にブラウザを開かない `-NoBrowser` オプションを追加した。

## 確認結果

- 4173が競合した状態で、4174を自動選択して起動できた。
- HTMLをステータス200、`text/html` で取得できた。
- WebP画像をステータス200、`image/webp`、40,856バイトで取得できた。
